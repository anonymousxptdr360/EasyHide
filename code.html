Confidentialité totale, par conception

Vos bordereaux ne quittent JAMAIS votre appareil : tout est traité localement dans votre navigateur. Aucun téléversement, aucun serveur, aucun compte, aucun pistage.

En savoir plus sur la confidentialité
  • Vos fichiers restent en mémoire vive et disparaissent à la fermeture de l'onglet. Rien n'est enregistré sur un disque distant.
  • Aucun cookie, aucune analytics, aucune publicité dans cet outil (c'est le but !).
  • Seul stockage local : votre langue, votre thème, et le composant de lecture des PDF (du code, jamais vos documents) pour fonctionner hors connexion ensuite.
  • Mode « Simple » : le texte sous les rectangles reste présent dans le PDF (sélectionnable). Pour des données sensibles à rendre irrécupérables, choisissez le mode « Sécurisé ».
  • Les liens externes (GitHub, Reddit, BentoPDF, stopbordo.odoo.com) s'ouvrent dans un nouvel onglet : c'est la seule façon de quitter cet outil.
  • Le code est public et vérifiable sur GitHub - téléchargez-le et utilisez-le sans connexion.

🛟 Roue de secours : BentoPDF (en ligne)

Si EasyHide ne convient pas, voici la méthode précise sur BentoPDF. Une connexion est nécessaire pour charger la page, puis tout se passe dans votre navigateur.

BentoPDF est confidentiel lui aussi

Votre document ne quitte JAMAIS votre appareil : BentoPDF exécute un moteur PDF (PDFium compilé en WebAssembly) directement dans votre navigateur. Seul le code de la page est téléchargé, jamais vos fichiers. C'est confirmé explicitement dans leur FAQ (« le document lui-même ne quitte jamais votre appareil »).

  1. Ouvrez ce lien précis (l'éditeur PDF) : www.bentopdf.com/fr/edit-pdf
  2. Ajoutez votre fichier - ⚠️ ce service n'accepte que les PDF.
  3. Allez dans « Shapes » (les formes).
  4. Cliquez sur le carré, puis cliquez sur la palette de couleurs située juste à gauche de la flèche qui pointe vers la gauche, et choisissez blanc.
  5. Placez et redimensionnez le carré sur la pub, puis exportez votre PDF.
